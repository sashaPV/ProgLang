В программе на С++ строка int c = a ++ b; разбивается на токены: int, c, =, a, ++, b, ;. Ошибка возникает из-за правила «максимального поглощения» в C++: компилятор объединяет два плюса в один токен инкремента (++). Получается выражение (a++) b. Так как между выражением a++ и переменной b нет никакого знака операции, компилятор выдает синтаксическую ошибку

В программе на Python строка c=a++b разбивается на токены: c, =, a, +, +, b. В Python нет оператора ++, поэтому интерпретатор видит здесь два отдельных плюса. Первый плюс — это бинарное сложение, а второй — унарный плюс (знак числа перед b). Выражение читается как a + (+b) и успешно вычисляется

### Задание 5 **(3)**
*Рассмотрим следующую программу на языке Python.*
```
print(*map(sum,zip(
    *[map(int,input().split()) for i in (1,2,3)]
    )))
```
Ключевые слова: for, in
Идентификаторы (имена): print, map, sum, zip, int, input
Литералы (фиксированные значения): 1, 2, 3
Операторы: *

 Какие из идентификаторов задают переменные, а какие - имена функций и методов?
Имена функций и методов print, map, sum, zip, int, input — встроенные функции; split — метод строк
Переменные: i — переменная цикла


input() — вызывается без параметров. Считывает строку текста, введенную пользователем
split() — вызывается у считанной строки без параметров. Бьет строку на отдельные слова по пробелам
map(int, ...) — параметры: функция типа int и список слов из split(). Превращает текстовые слова в целые числа
zip(...) — параметры: три списка чисел (так как цикл for сработал 3 раза, а звездочка * распаковала их). Группирует элементы списков по парам/тройкам (первый с первым, второй со вторым)
map(sum, ...) — параметры: функция sum и сгруппированные через zip числа. Считает сумму в каждой группе
print(...) — параметры: распакованные результаты сумм (через звездочку *). Выводит их на экран через пробел

Как она это делает:
1. Программа ждет от пользователя ввод три раза (из-за for i in (1,2,3))
2. Допустим, мы ввели три строки чисел:
	 Строка 1: 1 2 3
	 Строка 2: 10 20 30
    Строка 3: 100 200 300
3. Функция zip собирает их по столбикам: (1, 10, 100), (2, 20, 200), (3, 30, 300)
4. Функция sum считает сумму каждого столбика
